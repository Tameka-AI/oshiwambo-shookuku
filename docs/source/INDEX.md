## What each file contributes to the MVP

- **Aawambo 2026** — people, geography, 2023 census share, fourteen dialects. Home page.
- **Rituals and ceremonies** — lifecycle spine: initiation, modern-and-traditional marriage, omitima, omandjandja, omapunga, omatunda, slaughter, mourning, naming, oshipe, healing, wedding, twins, new house, cattle dance, epiitho.
- **Homestead** — fourteen places from eelo to the hoe store.
- **Marriage** — clan exogamy, preferential vs prohibited unions, residence after marriage.
- **Kinship** — aakwetu grades, address terms, dialect differences (Oshikwanyama, Oshimbadja, Oshimbalantu), clan father and justice.
- **Ethnobotany** — omugolo (return), omusati (peace in a new house), ekaka and omboga.
- **Greetings** — thirteen situations from morning to the royal house, plus poetic register.

Original `.docx` files stay the source of truth. Re-convert if the professor revises them.
